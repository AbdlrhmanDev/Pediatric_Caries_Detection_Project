# Frozen checkpoint access and integrity

The final trained model artifact is **not currently included** in this repository.

Expected file: `final_model/YOLO11s_Final/final_60epochs.pt` (project-internal Drive layout). Checkpoint SHA-256:

`19ce0e2ae9731a9acb5baeaa4cb514782aa182e7d916d8a101298dd59cdb077e`

The original 20 fold checkpoints are also not redistributed; identifiers are recorded under `manifests/checkpoint_sha256_verified.csv`.

If the authors confirm redistribution rights for pretrained components and trained weights, they can publish the **unaltered** checkpoint as a versioned GitHub Release or in Zenodo, cite the actual asset URL/DOI here, and instruct readers to verify the SHA-256 before evaluation. Until a working link has been published and checked, the manuscript should describe checkpoint access as restricted/by request rather than openly downloadable.

No placeholder URLs should be represented as active links. No checkpoint should be substituted simply because it shares the same architecture or training duration.
